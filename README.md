# Overley 🎯

Лёгкий оверлей-прицел для FPS-шутеров на Windows: рисует ваш собственный прицел поверх игры.
**Без инжекта, без чтения памяти игры, без симуляции ввода** — это отдельное прозрачное click-through окно, которое система отображает поверх игры (как Discord Overlay или Xbox Game Bar).

> **Статус: этап M0 (research-спайк).** План и спецификации готовы, принятые решения: **Rust + Tauri 2**, **только Windows**, **полностью open source и бесплатно**.
> Точка входа: **[`docs/PLAN.md`](docs/PLAN.md)** · прототип оверлея: [`spike/`](spike/) · референсный рендерер DSL: [`tools/render_preview.py`](tools/render_preview.py).

---

## Что умеет (по замыслу)

- **Замена курсора прицелом** — два режима: `center` (прицел в центре экрана, для FPS) и `cursor` (прицел следует за мышью). Три стратегии скрытия системного курсора с гарантированным восстановлением даже после аварийного завершения.
- **Авто-запуск вместе с программой** — наблюдатель процессов (имя процесса + активное окно) поднимает оверлей и применяет нужный пресет, когда стартует игра. В процесс игры мы не заходим.
- **Пресеты и профили** — «какой прицел для какой игры» + глобальный пресет по умолчанию + ручное переключение хоткеем. Пользователь полностью управляет пресетами: редактор, дублирование, импорт/экспорт одного файла `.ovcross`.
- **Галерея с инструкцией для ИИ** — карточка «Создать прицел с ИИ»: копируешь промпт → вставляешь в **любой** ИИ-чат (ChatGPT, Claude, Gemini, DeepSeek, локальная модель) → возвращаешь ответ в приложение → валидация, предпросмотр, сохранение. Приложение никуда не отправляет ваши данные.
- **Максимальная кастомизация** — 10 типов слоёв, градиенты, обводка, свечение, тени, анимации с 12 кривыми, реактивность на скорость мыши/кнопки/колесо, свои PNG/SVG.
- **Современный UI** — тёмная тема, живое превью на игровом фоне, послойный редактор, RU/EN, трей, онбординг.

## Ключевое ограничение (честно)

Оверлей виден в **оконном** и **borderless** режиме. В настоящем эксклюзивном fullscreen (FSE) DWM не композитит сторонние окна поверх игры — там прицела не будет. Приложение детектит этот случай и подсказывает переключить режим экрана. Подробности: [`docs/COMPATIBILITY.md`](docs/COMPATIBILITY.md).

## Формат прицела и примеры

Формат декларативный: `.ovcross` = один JSON-объект, проверяемый JSON Schema. Никакого кода и внешних ссылок — только геометрия, стили, анимации и ограниченные выражения.

```
schema/crosshair-v1.schema.json     # схема (draft 2020-12)
schema/tests/invalid/*.json         # 8 негативных тестов: обязаны отклоняться
schema/tests/ai-roundtrip/*.md      # сырые «ответы моделей» для теста импорта (M5-9)
presets/examples/*.ovcross.json     # 4 рабочих примера
tools/validate_presets.py           # CLI-валидатор (для CI и для пользователя)
tools/render_preview.py             # референсный рендерер DSL → PNG (эталон семантики, без зависимостей)
tools/normalize_ai_answer.py        # нормализатор «сырого» ответа ИИ → чистый JSON (эталон шага M5-4)
ci/validate-presets.yml             # GitHub Actions воркфлоу (см. комментарий внутри: как подключить)
```

Проверка формата (нужен `jsonschema`):

```bash
pip install jsonschema
python tools/validate_presets.py                 # примеры + негативные тесты
python tools/validate_presets.py my.ovcross.json # свой файл
```

Минимальный прицел:

```json
{ "format": "overley.crosshair", "version": 1,
  "layers": [ { "type": "circle", "r": 3, "fill": "#00FF88" } ] }
```

## Красные линии

Продукт сознательно **не** делает: инжект DLL, чтение/запись памяти игры, драйверы и обход античита, захват и анализ экрана игры, симуляцию ввода, макросы, привязку к игровым данным (отдача, здоровье, патроны). «Реактивные» прицелы реагируют только на движение мыши и время. Полный список и обоснование — [`docs/PLAN.md §3.3`](docs/PLAN.md) и [`docs/COMPATIBILITY.md §2`](docs/COMPATIBILITY.md).
