Пресет на приложение

        
ПриложениеПресетРежим

        

          
          
          
        

        
Автозапуск без инъекций. Хаб наблюдает за списком процессов (ReadProcessMemory не используется — только имена процессов) и показывает оверлей, когда целевой процесс появляется; плюс опция «запускать с Windows» через Планировщик задач. Никаких DLL, хуков и записи в чужую память — это красные линии продукта (PLAN §3.3).
