# «Инструкция для ИИ» в галерее прицелов — спецификация и готовые тексты

**Версия промпта:** `prompt-1.0.0` · **Версия схемы:** `crosshair v1`
**Родительские документы:** [`PLAN.md`](PLAN.md) (FR-D03…FR-D08) · [`CROSSHAIR_DSL.md`](CROSSHAIR_DSL.md)

Это тот самый сценарий: *пользователь копирует инструкцию → идёт на любой сайт с ИИ → копирует ответ в приложение → получает прицел*. Ниже — (1) как это устроено в UI, (2) готовые тексты промптов, которые приложение кладёт в буфер обмена, (3) follow-up промпты, (4) требования к реализации.

---

## 1. Как это выглядит в приложении

### 1.1 Точка входа в галерее

Первая карточка в сетке галереи — закреплённая, визуально отличающаяся (градиентная рамка, иконка ✨, подпись «ИИ»):

```
┌─────────────────────────────┐
│  ✨  Создать прицел с ИИ    │
│  Скопируй инструкцию —       │
│  вставь в любой чат с ИИ —   │
│  верни ответ сюда            │
│                             │
│        [ Открыть ]          │
└─────────────────────────────┘
```

Дополнительные точки входа: кнопка «Импорт» в шапке галереи, пункт в пустом состоянии раздела «Мои», пункт онбординга «Хочу свой прицел».

## 2. Основной промпт (RU) — кладётся в буфер по кнопке «Копировать промпт (RU)»

> below is the literal text the app copies; плейсхолдер `{ОПИСАНИЕ}` подставляется, если пользователь заполнил поле (иначе — строка по умолчанию).

```text
Ты — генератор прицелов (crosshair) для desktop-приложения Overley.
Сгенерируй ОДИН прицел в формате Overley Crosshair DSL v1.

═══ ПРАВИЛА ОТВЕТА (нарушение = непригодный результат) ═══
1. Ответ — ровно один JSON-объект. Никакого текста до/после, никаких markdown-заборчиков, никаких пояснений и извинений.
2. Только данные. Никакого кода, функций, скриптов, HTML, внешних ссылок.
3. Используй ТОЛЬКО перечисленные ниже поля. Любое неизвестное поле отклоняется приложением.
4. Все цвета — hex: "#RRGGBB" или "#RRGGBBAA". Именованные цвета ("red", "white") и rgba()/hsl() запрещены.
5. Координаты задаются ОТНОСИТЕЛЬНО ЦЕНТРА холста: центр = [0, 0], X вправо, Y вниз. Не используй координаты экрана.
6. Углы — в градусах (0 = вправо, по часовой). В выражениях sin/cos/tan — радианы.
7. Если в чём-то не уверен — упрощай. Простой валидный прицел лучше красивого невалидного.
8. Не добавляй комментарии в JSON.

═══ СТРУКТУРА ФАЙЛА ═══
{
  "format": "overley.crosshair",      // обязательно, ровно это значение
  "version": 1,                       // обязательно, ровно 1
  "meta": { "name": "до 64 симв.", "author": "ты", "description": "до 500", "tags": ["до 12 штук"], "license": "CC0-1.0", "source": "ai" },
  "canvas": { "size": [128, 128], "dpiScale": "auto" },   // size: 16..512 по каждой стороне
  "style": {
    "opacity": 1,                                        // 0..1
    "outline": { "color": "#000000CC", "width": 1.5, "enabled": true },  // единая чёрная обводка ПОД слоями
    "glow": { "color": "#7C4DFF55", "radius": 8, "enabled": false },      // свечение, radius 0..32
    "blend": "source-over",                              // source-over | screen | lighten | difference
    "pixelSnap": true
  },
  "layers": [ ...см. ниже... ],                          // 1..64 слоя
  "behavior": {
    "mode": "center",                                    // center | cursor | auto
    "offset": [0, 0],
    "hideWhen": { "appNotFocused": true, "altTab": true, "cursorVisible": false, "captureRunning": false },
    "cursorHide": "none"                                 // none | overlay-only | system-blank
  },
  "vars": { "имя": "выражение" },                        // до 16, необязательно
  "animate": [ ... ],                                    // до 16 глобальных анимаций, необязательно
  "reactive": { "smoothingMs": 80, "bindings": [ ... ] } // необязательно
}

═══ СЛОИ ═══
Общие поля слоя: "id" (только [A-Za-z0-9_-], уникален), "type", "fill" (цвет или градиент), "stroke", "strokeWidth" (0..32),
"shadow": { "color", "blur" (0..24), "offset": [x,y], "enabled" }, "blend", "visible" (bool или выражение),
"pos": [x, y] (смещение от центра), "rotate" (градусы), "scale": [sx, sy], "opacity" (0..1), "animate".

Типы и их ОБЯЗАТЕЛЬНЫЕ поля:
- "rect":    "size": [w, h]; опц. "radius" (скругление), "anchor": "center"|"top-left"|"bottom-center"
- "circle":  "r"
- "ring":    "r", "thickness"; опц. "dash": [on, off, ...] (до 8 чисел)
- "line":    "from": [x,y], "to": [x,y], "thickness"; опц. "cap": "butt"|"round"|"square"
- "poly":    "points": [[x,y], ...] (3..256); опц. "closed" (default true), "join": "miter"|"round"|"bevel"
- "arc":     "r", "thickness", "startAngle", "endAngle"; опц. "cap"
- "path":    "d" — SVG path data, команды M L H V C Q Z (до 2048 симв.); опц. "fillRule"
- "text":    "text" (до 16 симв.); опц. "font": {"family","size"(4..96),"weight"(100..900)}, "align"
- "image":   "src" — ТОЛЬКО data:image/png;base64,... или data:image/webp;base64,...; опц. "size", "tint", "filter"
- "group":   "layers": [...] (до 16 детей, вложенность до 4)

Порядок преобразований слоя: scale → rotate → перенос на pos.

Градиент вместо цвета:
{ "type": "linear", "from": [0,-16], "to": [0,16], "stops": [ {"color":"#00E5FFFF","at":0}, {"color":"#7C4DFFFF","at":1} ] }
("type": "radial" — from = центр, to = граница радиуса; "at" от 0 до 1)

═══ АНИМАЦИЯ (необязательно) ═══
В слое:
"animate": { "duration": 1400, "delay": 0, "easing": "easeInOutSine", "loop": true, "props": { "rotate": {"from":0,"to":360}, "opacity": {"keyframes":[0.2,1,0.2],"times":[0,0.5,1]} } }
- duration 50..60000 мс; loop: true | false | "pingpong"; keyframes и times одинаковой длины (2..16), times в 0..1 по возрастанию
- easing: linear, easeInQuad, easeOutQuad, easeInOutQuad, easeInCubic, easeOutCubic, easeInOutCubic, easeInOutSine, easeOutBack, easeOutElastic, steps4, steps8
- в корневом "animate" дополнительно обязательно "target": "<id слоя>"

═══ ВЫРАЖЕНИЯ И РЕАКТИВНОСТЬ (необязательно) ═══
В полях типа число (pos, rotate, scale, opacity, r, size, thickness, from, to, startAngle, endAngle, radius) можно
использовать строку-выражение длиной до 240 символов.
Разрешённые каналы: t (сек), mouseSpeed (px/с), mouseDX, mouseDY, mouseButton1..mouseButton5 (0|1), wheel, idle (сек), focused (0|1), fps.
Разрешённые функции: abs, sign, min, max, clamp, lerp, smoothstep, step, fract, mod, pow, sqrt, hypot, floor, ceil, round, sin, cos, tan.
Разрешённые операторы: + - * / % ( ) > < >= <= == != && || ! и тернарный ?: . Векторы: [x, y].
ВСЁ ОСТАЛЬНОЕ ЗАПРЕЩЕНО: любые другие имена, обращения к свойствам/объектам, скобки-индексы, запятые вне векторов и аргументов.

Привязки:
"reactive": { "smoothingMs": 80, "bindings": [
  { "target": "layers.n.pos", "value": "[0, -14 - 10 * speed + 8 * ads]", "range": [-40, 40] },
  { "target": "style.opacity", "value": "focused", "range": [0, 1] }
] }
- "target" — путь "layers.<id>.<поле>" или "style.<поле>"
- "range": [min, max] ОБЯЗАТЕЛЕН для каждой привязки (иначе импорт отклоняется)
- данные игры недоступны: нельзя привязываться к отдаче/здоровью/патронам — только к мыши и времени

═══ ЛИМИТЫ ═══
файл ≤ 512 КБ · слоёв ≤ 64 · group ≤ 4 уровня · точек в poly ≤ 256 · image data-URI ≤ 256 КБ и ≤ 512×512 px ·
анимаций ≤ 16 · привязок ≤ 32 · vars ≤ 16 · никаких внешних URL

═══ ПРИМЕР 1 — статичный крест (валиден) ═══
{"format":"overley.crosshair","version":1,"meta":{"name":"Classic Cross","source":"ai"},"canvas":{"size":[128,128],"dpiScale":"auto"},"style":{"outline":{"color":"#000000CC","width":1.5,"enabled":true}},"layers":[{"id":"top","type":"rect","size":[2,8],"pos":[0,-12],"fill":"#00FF88"},{"id":"bottom","type":"rect","size":[2,8],"pos":[0,12],"fill":"#00FF88"},{"id":"left","type":"rect","size":[8,2],"pos":[-12,0],"fill":"#00FF88"},{"id":"right","type":"rect","size":[8,2],"pos":[12,0],"fill":"#00FF88"},{"id":"dot","type":"circle","r":1,"fill":"#00FF88"}],"behavior":{"mode":"center","cursorHide":"none"}}

═══ ПРИМЕР 2 — анимированный и реактивный (валиден) ═══
{"format":"overley.crosshair","version":1,"meta":{"name":"Neon Pulse","source":"ai"},"canvas":{"size":[192,192],"dpiScale":"auto"},"style":{"outline":{"color":"#05010DCC","width":1.25,"enabled":true},"glow":{"color":"#7C4DFF55","radius":8,"enabled":true}},"vars":{"speed":"clamp(mouseSpeed / 3000, 0, 1)","breath":"0.5 + 0.5 * sin(t * 2.2)"},"layers":[{"id":"ring","type":"ring","r":22,"thickness":2,"fill":"#00E5FF","dash":[6,10],"animate":{"duration":6000,"easing":"linear","loop":true,"props":{"rotate":{"from":0,"to":360}}}},{"id":"n","type":"rect","size":[2,9],"pos":[0,-14],"fill":"#FFFFFF"},{"id":"s","type":"rect","size":[2,9],"pos":[0,14],"fill":"#FFFFFF"},{"id":"core","type":"circle","r":1.5,"fill":"#00E5FF","shadow":{"color":"#00E5FFAA","blur":6,"offset":[0,0],"enabled":true}}],"behavior":{"mode":"center","cursorHide":"overlay-only"},"reactive":{"smoothingMs":80,"bindings":[{"target":"layers.n.pos","value":"[0, -14 - 10 * speed]","range":[-40,40]},{"target":"layers.s.pos","value":"[0, 14 + 10 * speed]","range":[-40,40]}]}}

═══ ЗАДАЧА ═══
Сделай прицел по описанию пользователя. Описание: {ОПИСАНИЕ}

Перед тем как ответить, мысленно проверь (не выводи эту проверку):
- ровно один JSON-объект, начинается с "{" и заканчивается на "}"
- есть "format", "version", "layers"; у каждого слоя есть "type" и его обязательные поля
- все цвета в hex, все координаты относительно центра, все id уникальны
- нет неизвестных полей, нет внешних ссылок, нет текста вне JSON
- у каждой привязки в "reactive" есть "range"

ОТВЕТ:
```

**Значение `{ОПИСАНИЕ}` по умолчанию** (если поле пустое):
`хороший универсальный прицел для тактического шутера: тонкий крест с зазором в центре, читаемой чёрной обводкой и маленькой точкой; спокойные цвета, без лишней анимации`

## 3. Основной промпт (EN) — «Копировать промпт (EN)»

Тот же контракт на английском (нужен, потому что часть моделей лучше держит формат на EN). Структура 1:1 с RU-версией: правила ответа → структура файла → слои → анимация → выражения/реактивность → лимиты → 2 примера → задача → чек-лист. Полный текст хранится в `src-ui/src/i18n/prompts/en.ts` и генерируется из общего шаблона (§6), чтобы RU и EN не разъезжались.

Ключевые формулировки (для проверки при ревью):

```text
You are a crosshair generator for the Overley desktop app. Produce ONE valid JSON object in Overley Crosshair DSL v1.

ANSWER RULES (violating any of them makes the result unusable)
1. Reply with exactly one JSON object. No prose before or after, no markdown fences, no apologies.
2. Data only. No code, no functions, no scripts, no HTML, no external links.
3. Use ONLY the fields listed below. Unknown fields are rejected by the app.
4. All colors are hex: "#RRGGBB" or "#RRGGBBAA". Named colors and rgba()/hsl() are forbidden.
5. Coordinates are RELATIVE TO THE CANVAS CENTER: center = [0, 0], X right, Y down. Never use screen coordinates.
6. Angles are in degrees (0 = right, clockwise). sin/cos/tan inside expressions take radians.
7. When unsure — simplify. A simple valid crosshair beats a fancy invalid one.

TASK
Build a crosshair for this user request: {DESCRIPTION}
```

`{DESCRIPTION}` default (EN): `a clean all-round tactical crosshair: thin lines with a center gap, strong black outline and a small center dot; calm colors, no animation`.

## 4. Мини-промпт (для моделей с маленьким контекстом)

Если пользователь выбрал «короткий промпт» (или вставка полного не влезла в его модель):

```text
Верни ОДИН JSON-объект (без текста и без markdown) в формате Overley Crosshair DSL v1.
Обязательные поля: "format": "overley.crosshair", "version": 1, "layers": [...].
Слои: {"id","type","fill","pos":[x,y],"opacity"}, где type — один из rect(size:[w,h]), circle(r),
ring(r,thickness), line(from,to,thickness), poly(points), arc(r,thickness,startAngle,endAngle),
path(d), text(text), image(src=data:image/png;base64,...), group(layers).
Координаты относительно центра холста, цвета только hex (#RRGGBBAA), неизвестные поля запрещены,
внешние ссылки запрещены. canvas.size по умолчанию [128,128].
Задача: {ОПИСАНИЕ}
Пример валидного ответа:
{"format":"overley.crosshair","version":1,"meta":{"name":"Dot"},"layers":[{"id":"d","type":"circle","r":2.5,"fill":"#FF2E63"}],"style":{"outline":{"color":"#000000E6","width":2,"enabled":true}}}
```

## 5. Follow-up промпты (второй круг общения с ИИ)

Кнопки в диалоге импорта и в карточке пресета. Каждый промпт самодостаточен: содержит правило «только JSON», мини-спецификацию и исходный прицел.

### 5.1 «Исправь ошибки» (генерируется автоматически при отказе импорта)

```text
Приложение Overley отклонило этот JSON. Верни ИСПРАВЛЕННЫЙ JSON — один объект, без текста и без markdown-заборчиков.
Ничего не придумывай сверх схемы: используй только те же поля, что разрешены в Overley Crosshair DSL v1
(format "overley.crosshair", version 1; слои типов rect/circle/ring/line/poly/arc/path/text/image/group;
цвета только hex #RRGGBB или #RRGGBBAA; координаты относительно центра холста; у каждого reactive.binding обязателен "range").

ОШИБКИ ПРИЛОЖЕНИЯ:
{СПИСОК_ОШИБОК}

ИСХОДНЫЙ JSON:
{ИСХОДНЫЙ_JSON}
```

### 5.2 «Дай 5 вариантов»

```text
Сделай 5 РАЗНЫХ прицелов по этому описанию: {ОПИСАНИЕ}.
Ответ — один JSON-объект вида {"variants": [ <5 объектов формата Overley Crosshair DSL v1> ]}, без текста и markdown.
Каждый вариант — полностью самостоятельный и валидный. Различия должны быть заметны: форма, плотность, цвет, обводка.
Схему формата используй ту же, что и раньше (format/version/meta/canvas/style/layers/behavior).
```
> Приложение понимает `{"variants": [...]}` и показывает список для выбора — это единственный случай, когда принимается не корневой объект прицела.

### 5.3 «Перекрась»

```text
Перекрась этот прицел: {НОВОЕ_ОПИСАНИЕ_ЦВЕТА}. Верни полный JSON (Overley Crosshair DSL v1), один объект, без текста.
Геометрию не меняй. Цвета — только hex #RRGGBB или #RRGGBBAA.
ИСХОДНЫЙ JSON:
{ИСХОДНЫЙ_JSON}
```

### 5.4 «Добавь анимацию / реактивность»

```text
Добавь в этот прицел аккуратную анимацию и/или реакцию на движение мыши. Верни полный JSON (Overley Crosshair DSL v1), один объект, без текста.
Правила: анимаций ≤ 16, duration 50..60000 мс, easing из списка (linear, easeInOutSine, easeOutQuad, ...),
loop true|false|"pingpong". Реактивность — только через каналы t, mouseSpeed, mouseDX/DY, mouseButton1..5, wheel, idle, focused
и функции clamp/lerp/smoothstep/abs/min/max/sin/cos/... ; у каждой привязки ОБЯЗАТЕЛЬНО поле "range": [min, max].
Данные игры недоступны — никаких привязок к отдаче оружия.
ИСХОДНЫЙ JSON:
```

## 6. Требования к реализации

### 6.1 Сборка промпта (промт-билдер)

- Один шаблон на язык в `src-ui/src/i18n/prompts/{ru,en}.ts` (или `.md` в ресурсах) с плейсхолдерами: `{DESCRIPTION}`, `{SCHEMA_DIGEST}`, `{EXAMPLES}`, `{LIMITS}`, `{PROMPT_VERSION}`.
- `SCHEMA_DIGEST` генерируется **из реальной JSON-схемы** (`schema/crosshair-v1.schema.json`) скриптом `tools/build_prompt_digest.py` (создаётся на задаче M5-2), а не пишется руками: так схема и промпт не могут разъехаться. В дайджест идут: обязательные поля, enum'ы, числовые диапазоны, лимиты массивов. Сборка — часть CI; при изменении схемы промпт пересобирается автоматически, `promptVersion` инкрементируется.
- `EXAMPLES` — 2 фиксированных валидных примера (статичный + анимированный), берутся из `presets/examples/` и минифицируются. Тест CI: примеры в промпте обязаны проходить валидатор.
- Описание пользователя экранируется: обрезаем до 500 символов, убираем управляющие символы, экранируем кавычки/фигурные скобки, чтобы вставка не ломала структуру промпта и не позволяла «инъекцию инструкций» в наш шаблон.
- Копирование в буфер — с fallback'ом для систем без Clipboard API (временный textarea + `execCommand`), обязательный тост «Скопировано».

### 6.2 Импорт

Пайплайн — в [`ARCHITECTURE.md §9`](ARCHITECTURE.md): нормализация → схема → лимиты → семантика → пробный рендер → превью. Требования к UI:

- При открытии диалога автоматически подставлять буфер обмена, если он похож на JSON/SVG (и сообщать об этом, не молча).
- Показывать обнаруженный формат и статистику (слоёв, анимаций, привязок, размер).
- Все авто-исправления показывать списком («исправлено автоматически: …»), а не молча.
- Ошибки: путь к полю человеческим языком + ожидаемый формат + не более 20 в списке, остальные под «показать все».
- Кнопка «Копировать запрос на исправление» доступна всегда, когда есть ошибки.
- «Применить на 15 секунд» — живой try-on с автоматическим откатом и видимым таймером.
- Сохранение: имя (предзаполняется из `meta.name`, редактируется), теги, `source: "ai"`, опционально `aiModel` (выпадающий список «какой моделью сгенерировано» — для статистики и для повторных промптов).

### 6.3 Метрики успеха фичи (локальные, opt-in)

| Метрика | Цель |
| --- | --- |
| Доля импортов, принятых с первой попытки | ≥ 70% |
| Медианное время «открыл модалку → сохранил прицел» | ≤ 3 минут |
| Доля импортов, где понадобился follow-up «исправь» | ≤ 25% |
| Отказы из-за лимитов (бомбы/URL/скрипты) | фиксируем как инциденты безопасности, 100% отклонены |
| Доля пользователей галереи, открывших модалку ИИ | ≥ 30% (показатель заметности точки входа) |

Замер — локальный, без отправки, если телеметрия выключена.

### 6.4 Тесты

- **Snapshot-тест промпта:** собранный промпт (RU/EN, с описанием и без) сравнивается с эталоном; изменение схемы → осознанное обновление эталона + bump `promptVersion`.
- **Корпус реальных ответов моделей** (M5-9): ≥ 40 кейсов — валидные, с markdown-обёртками, с `rgba()`, с неизвестными полями, с текстом вокруг JSON, с несколькими вариантами, с битыми выражениями, с внешними URL, со `<script>` в описании. Ожидаемое поведение каждого зафиксировано.
- **Регрессия:** примеры из промпта всегда проходят `tools/validate_presets.py`.
- **Ручной прогон перед релизом:** 5 моделей × 3 описания → считаем долю принятых с первого раза, пишем в `docs/M5-prompt-eval.md`.

## 7. FAQ для пользователя (идёт в приложение и на сайт)

**Это безопасно? Я что-то отправляю из приложения?**
Нет. Приложение не ходит в сеть за тебя: ты сам копируешь текст и сам вставляешь его в ИИ-сервис. Ответ ты тоже приносишь сам, буфером обмена. Импорт проверяется локально.

**Какой ИИ подойдёт?**
Любой, который умеет выдавать JSON: ChatGPT, Claude, Gemini, DeepSeek, GigaChat, YandexGPT, Kimi, локальные модели (LM Studio/Ollama). Если модель слабая — используй «мини-промпт».

**ИИ выдал текст с пояснениями вокруг JSON. Это проблема?**
Нет: приложение само вытаскивает JSON из текста и снимает markdown-заборчики.

**ИИ выдал три варианта сразу.**
Тоже нормально — если ответ в виде `{"variants": [...]}`, приложение покажет список и даст выбрать. Если варианты просто написаны подряд, выбери один и вставь только его.

**Почему мой прицел отклонили?**
Смотри список ошибок в диалоге импорта: там указан путь к полю и ожидаемый формат. Нажми «Копировать запрос на исправление» и отправь его той же модели.

**Можно вставить не JSON, а картинку или SVG?**
Да: PNG/WebP (base64 или файл) и SVG поддерживаются. SVG растеризуется безопасно — скрипты внутри SVG не исполняются.

**Можно ли сделать прицел, который реагирует на отдачу в игре?**
Нет, и это сознательно. Приложение не читает игру. Реактивность доступна только на сигналы мыши и время (скорость движения, зажатые кнопки, колесо). Это же — причина, по которой оверлей совместим с античитами.

**Кому принадлежат сгенерированные прицелы?**
Тебе. Файл `.ovcross` можно менять, экспортировать и распространять (рекомендуемая лицензия — CC0).
