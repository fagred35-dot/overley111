# Overley — дорожная карта и декомпозиция работ

**Версия:** 0.1 · **Родительский документ:** [`PLAN.md`](PLAN.md)
**Оценка:** 124 рабочих дня (р.д.). Команда по умолчанию: 1 full-stack (Rust/TS) + дизайн part-time + QA part-time.
**Ворота между этапами:** этап не считается закрытым, пока не выполнены все его DoD. Этапы P2 не начинаются, пока не закрыты P0/P1 текущего этапа.

```
M0 ──► M1 ──► M2 ──► M3 ──► M4 ──► M5 ──► M6 ──► M7 ──► M8 ──► M9 ──► M10
 6      14     10     14     20     12     12     10      8     12      6   = 124 р.д.
 └──── играбельный MVP (44) ────┘ └───────── бета (54) ─────────┘ └── релиз (26) ──┘
```

Параллельно с любым этапом (не блокирует): контент — пресеты галереи, тексты, локализация, документация.

## Критический путь и буфер

Критический путь: **M0 → M1 → M2 → M3 → M4 → M5 → M9 → M10** (M6/M7/M8 частично параллельны при двух разработчиках).

Буфер не заложен в оценки намеренно; рекомендуется держать +20% на календарный срок. Основные источники перерасхода: (1) проблемы совместимости с играми/античита́ми в M9, (2) полировка редактора в M4, (3) подписанность/сторы в M8/M10.

## Definition of Done для задачи

Задача закрыта, если: код в репозитории; тесты (unit/golden по ситуации) зелёные в CI; нет новых предупреждений clippy/ts; NFR не деградировали (для задач, влияющих на рендер/ввод — замер приложен); поведение описано в пользовательской документации, если оно видно пользователю; негативные тесты формата не сломаны.

## Трекинг

Все задачи заводятся как GitHub Issues с меткой этапа (`M1`, `M2`, …) и приоритета (`P0/P1/P2`); ID из этого документа — в заголовке issue (например, «M2-5 Watchdog курсора»). Статус этапа — в `README.md` (таблица прогресса).
