# Crosshair DSL v1 — спецификация формата прицела

**Формат:** `overley.crosshair`, версия `1`
**Схема:** [`schema/crosshair-v1.schema.json`](../schema/crosshair-v1.schema.json) (JSON Schema draft 2020-12)
**Валидатор:** [`tools/validate_presets.py`](../tools/validate_presets.py) · **Примеры:** [`presets/examples/`](../presets/examples/)
**Этот документ — контракт для ИИ.** Он же (в сжатом виде) вшивается в промпт из [`AI_CROSSHAIR_PROMPT.md`](AI_CROSSHAIR_PROMPT.md).

---

## 1. Принципы

1. **Декларативность.** Прицел — это данные, а не код. Никаких функций, никаких вызовов, никакого доступа наружу. Данные проверяются схемой и компилируются в список операций отрисовки.
2. **Замкнутость.** Никаких внешних ресурсов: ни URL, ни ссылок на файлы. Картинки — только `data:` URI. Приложение в игровом режиме не выходит в сеть вообще.
3. **Детерминизм.** Одинаковый JSON → одинаковые пиксели на любой машине (с учётом DPI-масштаба).
4. **Безопасность по построению.** Всё, что может быть злоупотреблено (количество слоёв, размер картинки, длина выражения), ограничено числом; выход за лимит = отказ импорта с понятной причиной.
5. **Нулевая цена в покое.** Если в файле нет `animate`/`reactive`, прицел рендерится один раз и больше не перерисовывается.

## 2. Файл `.ovcross`

Расширение `.ovcross`, содержимое — один JSON-объект в UTF-8 без BOM. Приложение также принимает вставку JSON в диалог импорта и файлы `.json`.

Обязательные поля: `format`, `version`, `layers`. Всё остальное опционально и имеет значения по умолчанию. Неизвестные поля **отклоняются** (`unevaluatedProperties: false`) — это защита от опечаток ИИ.

Минимальный валидный прицел:

```json
{ "format": "overley.crosshair", "version": 1, "layers": [ { "type": "circle", "r": 3, "fill": "#00FF88" } ] }
```

## 3. Корневая структура

| Поле | Тип | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `format` | `"overley.crosshair"` | — | идентификатор формата |
| `version` | `1` | — | версия DSL |
| `meta` | object | `{}` | имя, автор, описание, теги, лицензия, источник |
| `canvas` | object | `{size:[128,128]}` | холст и точка прицеливания |
| `style` | object | `{}` | глобальные эффекты: прозрачность, обводка, свечение, режим наложения |
| `layers` | array 1..64 | — | слои прицела, рисуются по порядку |
| `behavior` | object | `{mode:"center"}` | режим позиционирования, offset, правила скрытия, скрытие курсора |
| `vars` | object ≤16 | `{}` | именованные выражения, переиспользуемые в анимациях/привязках |
| `animate` | array ≤16 | `[]` | глобальные анимации (то же, что `layer.animate`, но с `target`) |
| `reactive` | object | `{}` | привязки свойств к сигналам мыши/времени |

### 3.1 `meta`

| Поле | Ограничение |
| --- | --- |
| `name` | строка 1..64 |
| `author` | ≤ 64 |
| `description` | ≤ 500 |
| `tags` | ≤ 12 штук, каждая ≤ 24 символа, только буквы/цифры/`-`/`_`/пробел |
| `license` | ≤ 40 (рекомендуется `CC0-1.0`) |
| `source` | `builtin` \| `editor` \| `ai` \| `import` |
| `aiModel` | ≤ 64, свободный текст (какая модель сгенерировала) |

## 4. Система координат

- Холст `canvas.size` = `[ширина, высота]` в логических px, от 16 до 512. Рекомендуется квадрат.
- Точка прицеливания — `canvas.origin` (по умолчанию центр холста). Все координаты слоёв (`pos`, `from`, `to`, `points`, `d`) задаются **относительно origin**, а не относительно левого верхнего угла.
- Ось X вправо, ось Y **вниз** (экранная конвенция).
- Углы — в градусах, 0° = направление вправо (+X), увеличение по часовой стрелке. В выражениях тригонометрия (`sin/cos/tan`) принимает **радианы**.
- Порядок преобразований слоя: `scale` → `rotate` → перенос на `pos`. То есть точка `p` слоя попадает в `origin + pos + R(rotate) · (scale ⊙ p)`.
- `dpiScale: "auto"` масштабирует весь прицел под DPI монитора, чтобы физический размер был одинаковым на 100% и 200%.

## 5. `style` — глобальные эффекты

| Поле | Тип/диапазон | Что делает |
| --- | --- | --- |
| `opacity` | 0..1 | общая прозрачность прицела |
| `outline` | `{color, width 0..16, enabled}` | единая обводка: геометрия всех слоёв дополнительно обводится **под** слоями толщиной `strokeWidth слоя + 2 × outline.width`. Классический «чёрный контур», обеспечивающий читаемость на любом фоне |
| `glow` | `{color, radius 0..32, enabled}` | размытая копия всего прицела под ним (свечение) |
| `blend` | `source-over` \| `screen` \| `lighten` \| `difference` | режим наложения на изображение игры |
| `pixelSnap` | bool | округление координат до пиксельной сетки (чёткие тонкие линии на 1080p) |

Порядок отрисовки всего прицела: `glow` → `outline`-проход → слои (снизу вверх, каждый со своим `shadow` под собой) → применение `opacity`/`blend`.

## 6. `layers` — примитивы

Общие поля слоя:

| Поле | Тип | Комментарий |
| --- | --- | --- |
| `id` | `[A-Za-z0-9_-]{1,48}` | нужен для `animate.target` и `reactive.bindings.target`; должен быть уникальным |
| `type` | enum | см. ниже |
| `fill` | цвет или градиент | заливка |
| `stroke` | цвет | обводка самого слоя |
| `strokeWidth` | 0..32 | толщина обводки слоя |
| `shadow` | `{color, blur 0..24, offset, enabled}` | тень/свечение слоя |
| `blend` | как в `style` | режим наложения слоя |
| `visible` | bool или выражение | условная видимость |
| `pos` | `[num, num]` | смещение от origin (число или выражение) |
| `rotate` | num | градусы |
| `scale` | `[num, num]` | масштаб |
| `opacity` | 0..1 num | прозрачность слоя |
| `animate` | animation | анимация свойств этого слоя |

Типы:

| `type` | Обязательные поля | Дополнительные |
| --- | --- | --- |
| `rect` | `size: [w,h]` | `radius` (скругление), `anchor: center\|top-left\|bottom-center` |
| `circle` | `r` | — |
| `ring` | `r`, `thickness` | `dash: [on, off, …]` ≤ 8 значений |
| `line` | `from: [x,y]`, `to: [x,y]`, `thickness` | `cap: butt\|round\|square` |
| `poly` | `points: [[x,y],…]` 3..256 | `closed` (default true), `join: miter\|round\|bevel` |
| `arc` | `r`, `thickness`, `startAngle`, `endAngle` | `cap: butt\|round` |
| `path` | `d` (SVG path data, ≤ 2048 символов) | `fillRule: nonzero\|evenodd`. Поддерживаются команды `M L H V C Q Z` (абсолютные и относительные) |
| `text` | `text` (≤ 16 символов) | `font: {family, size 4..96, weight 100..900}`, `align: center\|left\|right` |
| `image` | `src` — только `data:image/png;base64,…` или `data:image/webp;base64,…` | `size: [w,h]`, `tint` (перекраска), `filter: none\|grayscale` |
| `group` | `layers: [1..16]` | вложенность ≤ 4 уровней; трансформации группы применяются к детям |

### 6.1 Цвета

- `#RGB`, `#RRGGBB`, `#RRGGBBAA` (hex, альфа последняя). Пример: `"#00FF88"`, `"#000000CC"`, `"#F00"`.
- Именованные цвета (`red`, `white`) **не поддерживаются** — только hex.
- Градиент:
  ```json
  { "type": "linear", "from": [0,-16], "to": [0,16],
    "stops": [ {"color":"#00E5FFFF","at":0}, {"color":"#7C4DFFFF","at":1} ] }
  ```
  `type: "radial"` использует `from` как центр и `to` как границу радиуса. `at` — 0..1.

## 7. Выражения

Выражение — строка ≤ 240 символов, вычисляется в мини-ВМ. Разрешено использовать в полях типа `num` (см. §6), в `animate.props.*.from/to/keyframes`, в `visible`, в `vars` и в `reactive.bindings.value`.

### 7.1 Грамматика

```ebnf
expr     = ternary ;
ternary  = orExpr , [ "?" , expr , ":" , expr ] ;
orExpr   = andExpr , { "||" , andExpr } ;
andExpr  = cmpExpr , { "&&" , cmpExpr } ;
cmpExpr  = addExpr , [ ( "==" | "!=" | ">=" | "<=" | ">" | "<" ) , addExpr ] ;
addExpr  = mulExpr , { ( "+" | "-" ) , mulExpr } ;
mulExpr  = unary , { ( "*" | "/" | "%" ) , unary } ;
unary    = ( "-" | "!" ) , unary | call | primary ;
call     = IDENT , "(" , expr , { "," , expr } , ")" ;
primary  = NUMBER | IDENT | "(" , expr , ")" | vector ;
vector   = "[" , expr , "," , expr , [ "," , expr , [ "," , expr ] ] , "]" ;
```

### 7.2 Каналы (единственные допустимые идентификаторы-данные)

| Канал | Диапазон | Смысл |
| --- | --- | --- |
| `t` | ≥ 0, сек | время с момента показа оверлея |
| `mouseSpeed` | ≥ 0, px/с | сглаженная скорость движения мыши |
| `mouseDX`, `mouseDY` | px | перемещение за последний кадр |
| `mouseButton1..5` | 0 \| 1 | ЛКМ, ПКМ, средняя, доп. 1, доп. 2 |
| `wheel` | -120..120 | последнее движение колеса, затухает за 250 мс |
| `idle` | ≥ 0, сек | сколько секунд мышь не двигалась |
| `focused` | 0 \| 1 | целевое приложение в фокусе |
| `fps` | ≥ 0 | оценка частоты презентаций оверлея |

Плюс имена из `vars`. **Любой другой идентификатор — ошибка импорта.** Обращений к объектам, индексации строк, свойств вроде `window.x` не существует.

### 7.3 Функции

`abs, sign, min(a,b), max(a,b), clamp(x,a,b), lerp(a,b,t), smoothstep(a,b,x), step(a,x), fract, mod(a,b), pow(a,b), sqrt, hypot(a,b), floor, ceil, round, sin, cos, tan` — всего 20, других нет.

### 7.4 Правила вычисления

- Все вычисления в `f64`; результат приводится к типу поля.
- `NaN`/`Inf` → значение по умолчанию поля + предупреждение в лог (рендер не падает).
- Результат привязок `reactive` **обязан** быть ограничен `range: [min,max]` (для защиты от уезда прицела за экран). Отсутствие `range` = ошибка импорта.
- Деление на ноль → `Inf` → правило выше.
- Выражения не имеют побочных эффектов, не могут зациклиться, не обращаются к памяти/файлам/сети.

Примеры:

```json
"vars": {
  "speed": "clamp(mouseSpeed / 3000, 0, 1)",
  "ads":   "mouseButton2",
  "breath":"0.5 + 0.5 * sin(t * 2.2)"
}
"reactive": { "bindings": [
  { "target": "layers.n.pos", "value": "[0, -14 - 10 * speed + 8 * ads]", "range": [-40, 40] },
  { "target": "style.opacity", "value": "focused", "range": [0, 1] }
]}
```

`target` — путь вида `layers.<id>.<поле>` или `style.<поле>`. Точка прицеливания при этом не смещается: двигаются только указанные свойства.

## 8. `animate`

```json
{
  "duration": 1400,        // 50..60000 мс
  "delay": 0,              // 0..60000 мс
  "easing": "easeInOutSine",
  "loop": true,            // true | false | "pingpong"
  "playWhen": "focused",   // необязательное выражение-условие
  "props": {
    "rotate":  { "from": 0, "to": 360 },
    "opacity": { "keyframes": [0.08, 0.22], "times": [0, 1] },
    "scale":   { "keyframes": [1, 1.25], "times": [0, 1] }
  }
}
```

- Внутри слоя `animate` анимирует свойства **этого** слоя. В корневом массиве `animate` обязателен `target: "<id слоя>"`.
- Анимируемые свойства: `pos`, `rotate`, `scale`, `opacity`, `r`, `size`, `thickness`, `fill`-непрозрачность — то есть любые поля типа `num`.
- `easing`: `linear`, `easeInQuad`, `easeOutQuad`, `easeInOutQuad`, `easeInCubic`, `easeOutCubic`, `easeInOutCubic`, `easeInOutSine`, `easeOutBack`, `easeOutElastic`, `steps4`, `steps8`.
- `keyframes` и `times` одинаковой длины (2..16), `times` в 0..1 по возрастанию.
- ≤ 16 треков на файл.

## 9. `behavior`

| Поле | Значения | Смысл |
| --- | --- | --- |
| `mode` | `center` \| `cursor` \| `auto` | где рисуется прицел: в центре активного окна игры / на системном курсоре / автоматически по профилю |
| `offset` | `[x, y]` | постоянное смещение в px |
| `hideWhen.appNotFocused` | bool (default true) | прятать, когда целевое окно не в фокусе |
| `hideWhen.altTab` | bool (default true) | прятать при alt-tab |
| `hideWhen.cursorVisible` | bool (default false) | прятать, когда виден системный курсор (чтобы не было двух прицелов) |
| `hideWhen.captureRunning` | bool (default false) | прятать при работающем захвате экрана (OBS/ShareX/PrintScreen) |
| `cursorHide` | `none` \| `overlay-only` \| `system-blank` | как обращаться с системным курсором (см. ARCHITECTURE §5) |
| `idleFade.afterMs` | 0..600000, 0 = выкл | через сколько простоя начинать затухание |
| `idleFade.toOpacity` | 0..1 | до какой прозрачности затухать |

## 10. Лимиты (отказ импорта при превышении)

| Параметр | Лимит |
| --- | --- |
| Размер файла | 512 КБ |
| Глубина JSON | 16 |
| Слоёв суммарно (с вложенными) | 64 |
| Вложенность `group` | 4 |
| Точек в `poly` | 256 |
| Длина `path.d` | 2048 символов |
| Изображение | data-URI ≤ 256 КБ, размеры ≤ 512×512 |
| Внешние URL | 0 (любые `http://`, `https://`, `//` — отказ) |
| `vars` / `reactive.bindings` / `animate` | 16 / 32 / 16 |
| Длина выражения | 240 символов |
| `canvas.size` | 16..512 по каждой стороне |
| Имя/теги | ≤ 64 / ≤ 12 × 24 |

## 11. Что запрещено (и почему)

| Запрет | Причина |
| --- | --- |
| Любые URL, кроме `data:image/png|webp;base64` | слежка/утечка IP, зависимость от сети |
| `<script>`, `javascript:`, HTML-разметка | XSS в превью, исполнение кода |
| `eval`, `function`, `require`, `import(` | исполнение произвольного кода |
| `__proto__`, `constructor` | атаки на десериализацию |
| Произвольный JS/Python/C# код в любом поле | формат декларативный; песочница для JS — отдельная опция фазы 2 |
| Обращения к данным игры (здоровье, отдача, патроны) | красная линия продукта: мы не читаем игру |
| Неизвестные поля | защита от опечаток и от «своевольного» расширения формата моделью |

## 12. Версионирование

- `version: 1` — единственная поддерживаемая сейчас. Всё, что не `1`, отклоняется с сообщением «обновите приложение / поправьте версию».
- Изменения формата — только аддитивные внутри v1 (новое опциональное поле). Ломающие изменения → `version: 2` + автоматическая миграция v1→v2 в приложении.
- Схема публикуется вместе с приложением и в репозитории, чтобы промпт и валидатор не разъезжались. Промпт для ИИ содержит `promptVersion` и версию схемы.

## 13. Порядок приёмки файла приложением

1. Размер и кодировка (UTF-8, ≤ 512 КБ).
2. Нормализация (снятие markdown-заборчиков, вытаскивание JSON, авто-исправления с уведомлением).
3. JSON Schema 2020-12 (строгий режим, неизвестные поля = ошибка).
4. Семантические лимиты (§10) и запрещённые токены (§11).
5. Семантика: уникальность `id`, существование `target` у `animate`/`bindings`, разрешённые идентификаторы в выражениях, компилируемость выражений, наличие `range` у привязок.
6. Пробный рендер одного кадра в offscreen (ловит «невидимый»/вырожденный прицел) + предупреждение, если все пиксели прозрачные.
7. Превью пользователю → сохранение.

## 14. Полный пример

```json
{
  "format": "overley.crosshair",
  "version": 1,
  "meta": {
    "name": "Neon Pulse Ring",
    "author": "you + AI",
    "tags": ["neon", "animated", "reactive"],
    "license": "CC0-1.0",
    "source": "ai",
    "aiModel": "generic-llm"
  },
  "canvas": { "size": [192, 192], "dpiScale": "auto" },
  "style": {
    "opacity": 1,
    "outline": { "color": "#05010DCC", "width": 1.25, "enabled": true },
    "glow": { "color": "#7C4DFF55", "radius": 8, "enabled": true }
  },
  "vars": { "speed": "clamp(mouseSpeed / 3000, 0, 1)", "ads": "mouseButton2" },
  "layers": [
    { "id": "ring", "type": "ring", "r": 22, "thickness": 2, "fill": "#00E5FF",
      "dash": [6, 10], "opacity": 0.85,
      "animate": { "duration": 6000, "easing": "linear", "loop": true,
                   "props": { "rotate": { "from": 0, "to": 360 } } } },
    { "id": "n", "type": "rect", "size": [2, 9], "pos": [0, -14], "fill": "#FFFFFF" },
    { "id": "s", "type": "rect", "size": [2, 9], "pos": [0, 14], "fill": "#FFFFFF" },
    { "id": "core", "type": "circle", "r": 1.5, "fill": "#00E5FF",
      "shadow": { "color": "#00E5FFAA", "blur": 6, "offset": [0, 0], "enabled": true } }

                "hideWhen": { "appNotFocused": true, "altTab": true } },
  "reactive": { "smoothingMs": 80, "bindings": [
    { "target": "layers.n.pos", "value": "[0, -14 - 10 * speed + 8 * ads]", "range": [-40, 40] },
    { "target": "layers.s.pos", "value": "[0, 14 + 10 * speed - 8 * ads]", "range": [-40, 40] }
  ] }
}
```

Больше примеров: [`presets/examples/`](../presets/examples/) — все четыре проходят валидатор.

## 15. Чек-лист валидности (его же видит ИИ в промпте)

- [ ] `format` = `"overley.crosshair"`, `version` = `1`
- [ ] `layers` — непустой массив, каждый слой имеет `type` и обязательные поля этого типа
- [ ] Все цвета — hex (`#RGB`, `#RRGGBB`, `#RRGGBBAA`), без именованных цветов и `rgba()`
- [ ] Нет внешних URL, нет HTML/JS, нет неизвестных полей
- [ ] Координаты относительно центра холста, значения в пределах 16..512
- [ ] Все `id` уникальны и состоят из `[A-Za-z0-9_-]`
- [ ] Каждая `reactive.binding` имеет `range`, а выражения используют только разрешённые каналы и функции
- [ ] Файл ≤ 512 КБ, слоёв ≤ 64, анимаций ≤ 16
